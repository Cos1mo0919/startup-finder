# v3.1 Stage B — public catalog presentation

The public navigation remains four items: Bosh sahifa, Loyihalar, Arxiv,
Manbalar. Home now ranks actual published projects with a documented neutral
internal fallback for unscored entries, plus Uzbekistan/Global and sector
summaries. The ordinary catalog keeps search and three country choices. It
shows project identity, sector, country, source date, concise description,
source count and the catalog score if present. An unscored card says
`Baholanmagan`; the neutral ranking constant is never exposed as a score.

Detail pages lead with what the project does and original sources. Problem,
audience, opportunity and detailed factor explanations appear only when data
exists. Unknown creator, country, problem and score are not replaced with
invented values. Broken/obvious publisher-logo images use a project-initial
fallback. Archive filters remain based on `published_at`; estimated source
dates are marked `taxminiy`.

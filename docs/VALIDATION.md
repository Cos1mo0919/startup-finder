## Что проверяют тесты

Частоты приоритетов и индивидуальные интервалы, пропуск не наступивших/выключенных источников, сохранение настройки оператора, сбой и восстановление source health, RSS/HTML/search адаптеры, отсутствие ключей, миграция и повторный аудит.

Evidence роли и детерминированный score, независимость цитат, низкий балл, отсутствие автора, будущий прототип, скрытый detail 404, сохранение rejected_candidates; дедупликация нескольких источников и прежнего first_seen. Различение проектов, мероприятий, приобретений компаний, идей и экосистемных новостей; event → follow-up → project с provenance. Несколько секторов, фильтры/статистика только видимых проектов; серьёзность проблемы не меняет полезность.

Сохранены тесты дат, цитат/имён/URL, AI/Brave контрактов, безопасности fetch/robots/DNS/редиректов, lease, расписания и повторной обработки после появления AI. Browser-тесты проверяют поиск/фильтры/переходы, кликабельную статистику, evidence и AI-раздел, реестр и debug на desktop/mobile. Фикстура AgroKo‘mak живёт только во временной БД.

## Живые данные

Первый radar-запуск (Run 10): 9 включённых источников, 28 обработанных кандидатов, 16 отклонений, 11 ожидающих анализа, 1 новое мероприятие, 0 новых проектов. Четыре поисковых профиля вернули requires_api_key; остальные пять коллекторов успешно получили ссылки: Spot UZ 20, Spot RU 20, UzHunt 5, IT Park 12, ICT Week 3. Лимит очереди и дедупликация означают, что не все полученные ссылки обрабатываются за один запуск.

Следующий запуск (Run 11) не опрашивал эти источники повторно: sources_checked=0. Перепроверены 11 ожидающих кандидатов; обнаруженное мероприятие из Spot требует Search API для поиска дополнительных публикаций. Статус partial отражает этот отсутствующий ключ, а не замаскированный успех.

Реальная старая запись @Hudud_gaz_taminot_bot сохранена в БД, но скрыта с причиной creator_unknown. Сравнение с `data/finder.sqlite3.pre-radar-backup` подтвердило прежние ID, first_seen и published_at. Основная лента пуста по правилам нового stop filter. Не добавлялись фиктивные проекты, фиктивные даты или авторы.

Рабочая БД и backup игнорируются Git. Полноценное live-покрытие регионов, AI-перевод и event search требуют отдельной проверки с ключами и доступными источниками. Mock-тесты не заменяют её.
